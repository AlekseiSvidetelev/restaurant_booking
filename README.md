# Ресторан "Гурман" - Система бронирования столиков
Проект представляет собой веб-приложение для бронирования столиков в ресторане "Гурман". Система позволяет пользователям просматривать доступные столики, бронировать их на удобное время, а также управлять своими бронированиями.

## Функциональные возможности
### Для пользователей:
Просмотр информации о ресторане и его услугах

Бронирование столиков с выбором даты, времени и количества гостей

Просмотр истории бронирований

Управление активными бронированиями (отмена)

Система обратной связи с администрацией ресторана

### Для администраторов:
Управление столиками (добавление, редактирование, удаление)

Просмотр и управление бронированиями (отмена, изменение статуса)

Управление пользователями

## Установка и запуск
### Предварительные требования
Docker и Docker Compose установленные на системе

Git для клонирования репозитория

Клонирование репозитория

`git clone git@github.com:AlekseiSvidetelev/restaurant_booking.git`

`cd restaurant_booking`

### Настройка переменных окружения
Создайте файл .env в корневой директории проекта на основе примера:

### Настройки базы данных
POSTGRES_DB=restaurant_db
POSTGRES_USER=restaurant_user
POSTGRES_PASSWORD=secure_password

### Настройки Django
SECRET_KEY=your-secret-key-here
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

### Настройки электронной почты
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password

### Настройки для обратной связи
HELP_EMAIL=help@example.com,help2@example.ru

## Запуск приложения
Соберите и запустите контейнеры:

`docker-compose up --build`
При первом запуске примените миграции базы данных:

`docker-compose exec backend python manage.py csu`

Команда csu создаст суперпользователя с email admin@example.com и паролем 123456.

После выполнения этих шагов приложение будет доступно по адресу: http://localhost

Админ-панель Django доступна по адресу: http://localhost/admin

## Настройка прав доступа для персонала
Для назначения прав персоналу:

Войдите в админ-панель с учетной записью суперпользователя.

Перейдите в раздел "Группы" и создайте новую группу (например, "Менеджеры").

Назначьте группе необходимые права:

booking | reservation | Может изменять статус бронирования - для изменения статуса бронирований

booking | table | Может изменять стол - для управления столиками

Добавьте пользователей в эту группу.

Персоналу с этими правами будет доступно:

Создание и редактирование столиков

Изменение статуса бронирований (подтверждение, завершение, отметка о неявке)

Удаление столиков и бронирований доступно только суперпользователям и пользователь с определенными правами.

## Использование

### Для пользователей:
Перейдите на главную страницу

Зарегистрируйтесь или войдите в систему

Перейдите в раздел бронирования

Выберите дату, время и количество гостей

Выберите подходящий столик из доступных

Подтвердите бронирование

### Для администраторов:
Войдите в админ-панель по адресу /admin

Управляйте столиками через раздел "Tables"

Просматривайте и управляйте бронированиями через раздел "Reservations"

Управляйте пользователями через раздел "Users"

## Обратная связь
### Настройка обратной связи
Для настройки обратной связи необходимо в файле .env указать email-адреса, на которые будут отправляться сообщения:

HELP_EMAIL=help@example.com,help2@example.ru, ...

### Функционал обратной связи
Система предоставляет пользователям возможность связаться с администрацией ресторана через форму обратной связи. Это позволяет:

Задавать вопросы о бронировании

Сообщать о специальных запросах (праздники, мероприятия)

Оставлять отзывы о посещении ресторана

Сообщать о проблемах или жалобах

Предлагать идеи для улучшения сервиса

### Как отправить сообщение
Перейдите на страницу "Контакты" через главное меню

Заполните форму обратной связи:

Тема письма - выберите категорию вашего обращения

Email - укажите вашу электронную почту для ответа

Сообщение - подробно опишите ваш вопрос или предложение

Нажмите кнопку "Отправить сообщение"

### Обработка обращений
Все сообщения, отправленные через форму обратной связи, регистрируются в системе и отправляются на email-адреса, указанные в HELP_EMAIL. Также сообщения сохраняются в базе данных для последующего анализа.
